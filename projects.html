My Projects

Here are some of the key projects I've worked on, showcasing my expertise in full-stack development, system design, and product execution.

Research Portal

Full Stack

A centralized web platform designed to connect students with ongoing research opportunities within the university. The portal allows faculty members to list research projects with detailed descriptions, while students can explore opportunities, apply, and track their application status through dashboards. The system focuses on structured data handling, role-based access, and a smooth user experience to bridge the gap between students and research mentors.

Key Focus Areas:

Research collaboration, authentication, dashboards, application tracking, structured data management.

Laundry Management System

Real-time

A web-based solution aimed at improving the laundry experience for students by providing real-time machine availability and usage tracking. The system enables users to check live machine status, log requests, receive notifications, and view usage history. This project emphasizes real-time updates, user convenience, and efficient resource utilization within a campus environment.

Key Focus Areas:

Real-time status tracking, notifications, usage analytics, student-centric design.

Rehabilitation Centre System

Healthcare

A centralized management platform built to synchronize data across rehabilitation centres in India. The system supports role-based access for Super Admins and Centre Admins, allowing efficient patient record management, history tracking, centre-level query handling, and issuing guidelines or orders to individual or multiple centres. The project focuses on scalability, data consistency, and administrative efficiency.

Key Focus Areas:

Role-based access control, centralized data management, healthcare administration workflows.
