# Tanishk Mittal Portfolio

Next.js portfolio for Tanishk Mittal, focused on full-stack development, intelligent systems, research work, academic achievements, and leadership.

## Commands

```bash
pnpm install
pnpm run dev
pnpm run lint
pnpm run typecheck
pnpm run build
```

Public profile facts, project links, SEO configuration, and résumé paths are centralized in `data/portfolio.ts`.
